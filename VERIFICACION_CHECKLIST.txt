✨ FLUJO DE SINCRONIZACIÓN

1. Usuario edita cotización en frontend
2. Click en "Guardar en nube"
3. Frontend recolecta todos los datos
4. POST a http://localhost:3001/api/cotizaciones
5. Backend recibe y valida
6. Guarda en SQLite (base de datos local)
7. API de GitHub:
   - Autentica con token
   - Crea/actualiza archivo JSON
   - Genera commit automático
8. Frontend recibe confirmación:
   - {success: true, synced: true, githubCommit: "abc123"}
9. Mostrar "✓ Guardado y sincronizado"
10. Cotización disponible en:
    - Base de datos local (SQLite)
    - Repositorio GitHub
    - Historial en /api/sync-log

Sincronización automática:
- Ocurre cada 30 segundos
- No interfiere con usuario
- Funciona en background
- Se ejecuta aunque usuario no haga nada

Modo offline:
- Si no hay servidor: guarda en SQLite (localmente)
- Si se desconecta internet: continúa guardando local
- Cuando se reconecta: sincroniza cambios pendientes
- Resultado: nunca pierde datos ✓

📊 ESTRUCTURA DE DATOS

Base de Datos SQLite:

TABLE: cotizaciones
├── id (Integer PK)
├── quote_number (Text UNIQUE)
├── data (JSON)
├── created_at (Datetime)
├── updated_at (Datetime)
├── synced_to_github (Integer: 0/1)
└── github_commit_sha (Text)

TABLE: sync_log
├── id (Integer PK)
├── action (Text: save, delete, sync)
├── quote_number (Text)
├── status (Text: success, error, pending)
├── message (Text)
└── timestamp (Datetime)

Archivo JSON en GitHub:

cotizaciones/
├── COT-2026-001.json
├── COT-2026-002.json
└── ...

Formato del JSON:
{
  "quoteNumber": "COT-2026-001",
  "companyData": { /* ... */ },
  "clientData": { /* ... */ },
  "items": [ /* ... */ ],
  "quoteDetails": { /* ... */ },
  "signer": { /* ... */ },
  "utility": { /* ... */ },
  "timestamp": "2026-10-10T14:30:00Z"
}

🔗 ENDPOINTS API

Health Check:
  GET /api/health
  Response: { status: "ok", github_configured: true, timestamp: "..." }

Guardar Cotización:
  POST /api/cotizaciones
  Body: { quoteNumber: "COT-2026-001", data: { /* ... */ } }
  Response: { success: true, synced: true, githubCommit: "abc123" }

Obtener Cotización:
  GET /api/cotizaciones/COT-2026-001
  Response: { success: true, data: { quoteNumber, data, timestamps, ... } }

Listar Todas:
  GET /api/cotizaciones
  Response: { success: true, count: 5, data: [ /* ... */ ] }

Eliminar Cotización:
  DELETE /api/cotizaciones/COT-2026-001
  Response: { success: true, message: "Eliminada del almacenamiento local" }

Sincronizar Manual:
  POST /api/sync-github
  Body: { quoteNumber: "COT-2026-001" }
  Response: { success: true, message: "...", commitSha: "...", url: "..." }

Ver Historial:
  GET /api/sync-log
  Response: { success: true, count: 10, data: [ /* ... */ ] }
