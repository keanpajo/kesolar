¿QUÉ TIENES QUE HACER AHORA?

1. OBTENER GITHUB TOKEN (5 minutos)
   └─ Ve a: https://github.com/settings/tokens
   └─ Crea "Generate new token (classic)"
   └─ Marca scope: ✓ repo
   └─ Copia el token (40+ caracteres)
   └─ Guárdalo en lugar seguro

2. CREAR REPOSITORIO (2 minutos)
   └─ Ve a: https://github.com/new
   └─ Nombre: cotizaciones
   └─ Visibilidad: Private (recomendado)
   └─ NO inicialices con README
   └─ Crea el repositorio

3. CONFIGURAR BACKEND (3 minutos)
   └─ Abre PowerShell en: C:\Users\kevin\Documents\plataforma edicion\backend
   └─ npm install
   └─ Edita archivo .env
   └─ Agrega:
      GITHUB_TOKEN=ghp_tu_token_de_40_caracteres
      GITHUB_REPO=tu-usuario/cotizaciones
      PORT=3001

4. INICIAR SERVIDOR (1 minuto)
   └─ npm start
   └─ Deberías ver:
      ✓ Servidor escuchando en http://localhost:3001
      ✓ GitHub sincronización activada: tu-usuario/cotizaciones

5. USAR LA PLATAFORMA (Ahora!)
   └─ Abre index.html
   └─ Completa una cotización
   └─ Click en "Guardar en nube"
   └─ ✓ ¡Se sincroniza automáticamente!
