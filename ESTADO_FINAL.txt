🚀 CÓMO USAR (Paso a Paso)

1️⃣  Abre: index.html en navegador
    └─ Verás la plataforma de cotizaciones

2️⃣  En "Mi Empresa":
    ├─ Sube un LOGO (imagen)
    ├─ Llena Nombre, RUT, Teléfono, Email
    └─ Todos los campos que quieras

3️⃣  En "Datos del Cliente":
    ├─ Nombre/Empresa
    ├─ RUT/DNI
    ├─ Dirección
    └─ Email

4️⃣  En "Firma Digital":
    ├─ Sube imagen de firma (PNG/JPG)
    └─ Llena nombre, cargo, teléfono

5️⃣  Haz clic en "GUARDAR EN NUBE" ☁️
    ├─ Se suben TODOS los datos a GitHub
    ├─ Se sube el logo a GitHub
    ├─ Se sube la firma a GitHub
    └─ ✓ GUARDADO PERMANENTEMENTE

6️⃣  Cierra navegador y vuelve mañana
    ├─ Abre index.html nuevamente
    ├─ Logo se carga desde GitHub ✓
    ├─ Datos se cargan desde GitHub ✓
    └─ ¡Nada desapareció!
