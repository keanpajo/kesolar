🚀 PASOS PARA ACTIVAR:

1. Obtener GitHub Token:
   → https://github.com/settings/tokens
   → Crear token con scope "repo"
   → Copiar token de 40+ caracteres

2. Crear Repositorio GitHub:
   → https://github.com/new
   → Nombre: "cotizaciones"
   → Visibilidad: Private o Public

3. Configurar Backend:
   cd "c:\Users\kevin\Documents\plataforma edicion\backend"
   npm install
   copy .env.example .env
   
   → Editar .env:
      GITHUB_TOKEN=tu_token_aqui
      GITHUB_REPO=tu-usuario/cotizaciones
      PORT=3001

4. Iniciar Servidor:
   npm start
   
   Deberías ver:
   ✓ Servidor escuchando en http://localhost:3001
   ✓ GitHub sincronización activada: tu-usuario/cotizaciones

5. Usar la Plataforma:
   → Abre index.html en navegador
   → Completa la cotización
   → Click en "Guardar en nube" ☁️
   → Automáticamente se sincroniza a GitHub

🆘 TROUBLESHOOTING:

Problema: "Servidor no disponible"
→ Verifica: npm start está corriendo
→ Puerto 3001 no está en uso
→ Prueba: curl http://localhost:3001/api/health

Problema: "GitHub no configurado"
→ Verifica: .env tiene GITHUB_TOKEN y GITHUB_REPO
→ Prueba: GET /api/health debe mostrar github_configured: true

Problema: "Error al sincronizar"
→ Verifica: Token es válido (https://github.com/settings/tokens)
→ Verifica: Repo existe en GitHub
→ Verifica: Conexión a internet

Problema: "Puerto ya en uso"
→ Cambia en .env: PORT=3002
