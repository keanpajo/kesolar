   → Abre: backend/.env

   PORT=3001
   GITHUB_TOKEN=tu_token_aqui
   GITHUB_REPO=keanpajo/kesolar
   GITHUB_BRANCH=main
   ─────────────────────────────────────

3. INSTALAR Y EJECUTAR
   PowerShell:
   
   cd "C:\Users\kevin\Documents\plataforma edicion\backend"
   npm install
   npm start

   Deberías ver:
   ✓ Servidor escuchando en http://localhost:3001
   ✓ GitHub sincronización activada: keanpajo/kesolar
