Próximos Pasos

  1. Edita backend/.env con tus credenciales de GitHub
  2. Copia tu GitHub Token desde: https://github.com/settings/tokens
  3. Copia tu repositorio en formato: usuario/repositorio
  4. Reinicia el servidor: npm start
  5. Los cambios se sincronizarán automáticamente cada 30 segundos
