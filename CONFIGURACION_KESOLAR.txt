✓ El logo que subas se guarda en la nube (carpeta /cotizaciones/)

CONFIGURACIÓN (3 PASOS)

1️⃣ Crear/Copiar tu GitHub Token

   Ve a: https://github.com/settings/tokens
   
   Si YA TIENES uno, usa ese. Si no, crea uno nuevo:
   - Click "Generate new token (classic)"
   - Note: "Cotizaciones KESOLAR"
   - Scope: ✓ repo
   - Copy token

2️⃣ Configurar el archivo .env

   En: backend/.env
   
   Cambia:
   GITHUB_TOKEN=tu_token_aqui
   GITHUB_REPO=keanpajo/kesolar
   GITHUB_BRANCH=main
   PORT=3001

3️⃣ Instalar y ejecutar

   PowerShell:
   cd backend
   npm install
   npm start

EJEMPLO DE FLUJO

1. Usuario abre index.html
2. Carga datos guardados (logo, firma, datos empresa) desde GitHub
3. Usuario CAMBIA el logo o datos
4. Usuario hace click en "Guardar en nube"
5. ✓ Logo se sube a GitHub (cotizaciones/COT-2026-001-logo.png)
6. ✓ Datos se guardan (cotizaciones/COT-2026-001.json)
7. ✓ Cambios son PERMANENTES
8. Usuario vuelve a abrir página mañana
9. ✓ El logo SIGUE AHÍ (cargado desde GitHub)

ESPECIFICIDADES

• El número de cotización es la clave identificadora
  → Cada número = cotización diferente
  → COT-2026-001, COT-2026-002, etc.

• Puedes tener múltiples cotizaciones
  → Cada una con su propio logo
  → Cada una con sus propios datos

• Auto-sincronización
  → Cada 30 segundos los cambios se guardan
  → No tienes que hacer click si no quieres

• Modo offline
  → Funciona sin internet
  → Se sincroniza cuando reconectas
